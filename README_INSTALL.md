# WITUP GENESIS - Deploy Kit

Benvenuto nel Kit di Installazione di WITUP. Questo pacchetto contiene tutto il necessario per replicare lo stack tecnologico e le configurazioni standard.

## Contenuto del Kit
- `BLUEPRINT_TEMPLATE.md`: Il blueprint architetturale master.
- `.clauderules-ux`: Regole per l'agente specializzato in UX/UI.
- `.spec/templates/ux/`: Template e regole dettagliate per l'interfaccia utente.
- `GENESIS_PROMPT.txt`: Il prompt di attivazione per l'installer AI.

## Istruzioni per l'uso
1. Copia la cartella `_deploy_kit` nella root del nuovo progetto.
2. Fornisci il contenuto di `GENESIS_PROMPT.txt` all'assistente AI per avviare la procedura di installazione automatica.
3. Segui le istruzioni fornite dall'AI per completare l'inizializzazione del progetto.
