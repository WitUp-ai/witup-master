# Cartella Specifiche (.spec)
Questa cartella contiene la documentazione tecnica generata dall'AI prima della scrittura del codice.

## Struttura Standard
- `db_schema.md`: Struttura del database (Tabelle, Relazioni).
- `features/*.md`: Dettagli operativi delle singole funzionalità.
- `architecture.md`: Scelte architetturali macro.

## Regola d'Oro
Nessuna riga di codice viene scritta in `/src` se non è stata prima definita e approvata qui.
